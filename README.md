# Clipwave Site (Static)

A simple static landing page for **Clipwave** built with plain **HTML**, **CSS**, and **JavaScript**.

## Files
- `index.html` — page structure/content
- `style.css` — styles and responsive layout
- `script.js` — small UI interactions (mobile menu, scan-flow preview)

## Host on GitHub Pages
1. Create a new GitHub repository (or use an existing one).
2. Upload these files to the repository root (or the `/docs` folder if you configure Pages to use it).
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your branch (e.g. `main`) and folder (`/root` or `/docs`), then save.
6. Your site will be published at the GitHub Pages URL shown in settings.

## Note
This is a static promotional/info site. The full Clipwave application (video ingest, scanning, rendering with ffmpeg/yt-dlp, database, etc.) requires a server/runtime and cannot run as a static GitHub Pages site by itself.
