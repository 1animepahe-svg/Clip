# Clipwave

A manual, on-device browser video editor. Choose a local video, trim it, choose a format, add an optional manual caption, then export and download a WebM. Limit: 500 MiB source and 120 seconds per export. Keep the tab visible; the library is temporary, so download clips before leaving.

This limited browser editor replaces missing application source. It does not provide AI highlights, URL imports, automatic subtitles, MP4 exports, accounts or background processing. Browser and device compatibility varies. Use video you have permission to edit.

The working editor is index.html, clipwave.css and clipwave.js. Static hosting requires no backend or API key. Other server configuration and generated build manifests are incomplete remnants, not a runnable server. Do not add secrets to this public repository.
