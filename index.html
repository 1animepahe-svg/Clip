Features

Built for finding and clipping the best moments without a complicated workflow.

Multi-source ingest

Work with links from platforms like YouTube, Twitch, Kick, TikTok, Instagram, or upload your own files.

Smart scanning

Scan selected windows of long videos to quickly surface promising moments instead of processing everything blindly.

Clip length control

Choose target clip lengths (like 30s, 1m, 1.5m, 2m, or auto) before cutting/scanning to match your goals.

Formats & focus

Generate clips in different aspect ratios and framing/focus options to fit shorts, reels, and wide formats.

Captions from speech

Burn in captions from real transcripts when available, so clips are easier to follow and more shareable.

Fast iteration

Adjust settings, rescan windows, and render clips with audio preserved for the full clip duration.

How it works

  1. Add a source: paste a video/stream URL or upload a file.
  2. Configure scan: pick the time window, target clip length, format, focus, and caption options.
  3. Find moments: Clipwave analyzes the selected section and suggests highlight clips.
  4. Render & export: generate clips and download the versions you want to post.

FAQ

Can I choose clip length before scanning?

Yes — you can select a target clip length (or auto) so generated moments better match the style you need.

Does it support captions?

Clipwave can add burned-in captions from real speech transcripts when transcription is available/configured in the full app.

Can this static site run the full Clipwave app?

No. This is a static landing page (HTML/CSS/JS) for GitHub Pages. The full Clipwave app requires a server environment with dependencies like Node.js, ffmpeg, and yt-dlp for ingesting and rendering.
